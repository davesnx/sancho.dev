## An island

- `counter.mlx` with `let[@client]`; Melange compiles it to JavaScript
- State and effects: the component renders once, and each part of the markup that reads a State becomes a hole. A write updates only the holes that read it. Link to `docs/state.md` for depth
- An island takes server data as props; the data is encoded on the server and decoded in the browser
- Start strategies, with the real syntax (`start=`): `Load`, `Idle`, `Visible`, `Interaction`, and `Lazy` by a trigger. Each island downloads only when it is needed
- A few sentences on Melange: it compiles OCaml to JavaScript, so the same component runs on the server (native) and in the browser. Link to the post "why-melange"
- Introduces: island, State, hole, Melange
