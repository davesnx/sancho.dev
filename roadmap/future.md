## Theme experiments

## Decorative backgrounds

- Square appearance effect inspired by [verses.xyz](https://verses.xyz/).
- Dimmed loaded JavaScript background inspired by [pham.codes](https://pham.codes/).
- Pointer-driven CSS shader inspired by [chenglou.me](https://chenglou.me/pure-css-shaders-art/ringBenchmarks/ringPureJS.html).
- Repeating SVG patterns inspired by [daniloleal.co](https://daniloleal.co/til/repeating-pattern-svg).

These effects must remain decorative, respect reduced motion, avoid pointer-only behavior, and prove that they do not harm reading or performance before adoption.

### Card

A private-discovery `/card` route with no main menu or footer. It would act like a minimal card given to a stranger and contain name, username, role, Home, GitHub, X, and an optional Telegram contact. References: [morajabi.com](https://morajabi.com/?ref=deadsimplesites) and [p.cv](https://p.cv/?ref=deadsimplesites).
